## Important notes & decisions
- **The nav responsive CSS is duplicated in THREE files** — `Shell.astro`, `SpaLayout.astro`, AND `pages/[locale]/index.astro` (home isn't Shell-wrapped). Always edit all three or the home page silently keeps old behavior. (Also saved this to Claude's auto-memory.)
- The SPA (`app.jsx`) has **no popstate/hashchange listener**, so `history.back()` would desync it — left the SPA `ArticlePage` back button alone. It's also not the live reader anymore (`go({name:'article'})` routes to the SSR `p/[slug].astro`).
- The brief "burger pops in and shoves the buttons" flash on refresh is **dev-only Vite FOUC** (styles injected via JS in dev) — won't happen in the production build.
- Everything browser-verified at 1024 / 570 / 390 via the preview tools (measured real DOM gaps since screenshots sometimes hang); **0 console errors**.
