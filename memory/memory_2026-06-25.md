## Important notes & decisions
- **Two CSS gotchas learned (write these on the wall):** (1) Astro `<style>` is *scoped* — it can't style our React header/footer islands; island CSS must be `is:global`. (2) Inline React styles can't be media-queried, so responsive islands use utility classes (`.spa-g3`, `.nav-burger`, etc.) overridden by global `!important` rules.
- Gutter scale is now 32px desktop / 24px tablet / 20px phone, consistent across the site.
- Mobile collapse breakpoint is 820px on purpose (so iPad portrait at 768 gets the clean mobile layout, not a cramped desktop one).
- The error sink (`report.js`) is console-only until deploy day sets `PUBLIC_ERR_SINK` (or we wire Sentry) + a backend `/client-error` endpoint.
