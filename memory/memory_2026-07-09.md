## Laws adopted (now in CLAUDE.md)
- Never reuse a pg pool across Worker requests over Hyperdrive (hang → 500s).
- Per-user data is NEVER cached; getDbCached is content-only.
- Editor saves ≤1/30s, only on change, never silently lost; editor rate limits
  per-minute, never per-hour.
- Free-plan KV (1,000 writes/day) is an outage waiting to happen — Workers Paid.
