## Important notes & decisions
- Portability law: D1 now, Postgres later with zero rewrite. No `AUTOINCREMENT`, no FTS5, no `json_*()`, no `WITHOUT ROWID`. IDs = `<prefix>_<nanoid21>`. Timestamps = bigint ms. Booleans stored as 0/1.
- Auth model copied from Hall of Fables: HS256 JWT in memory (15 min) + opaque refresh token in HttpOnly+Secure+SameSite=Strict cookie `n101_rt` scoped to `/auth` on backend host. Rotation + family revoke on reuse.
- Dev URLs always localhost: frontend :4321, backend :8787. Prod swap to `nihon101.com` + `api.nihon101.com` at deploy.
- Resend is only for password reset emails. No newsletter, no notification emails.
- Tone for the project: wholesome, simple, Japan-focused. Monetization is AdSense only — no popup ad networks.
