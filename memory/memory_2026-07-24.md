## Important notes & decisions
- **The `desc nulls last` trap** bit both repos: Drizzle's `.desc()` indexes are NULLS LAST, but a plain `desc()` query is NULLS FIRST, so the index silently goes unused. Always spell it `desc nulls last` (Nihon101 has a `descNullsLast()` helper now). Verify any `.desc()` index with a query plan.
- **Migrate the prod DB BEFORE deploying the Worker** — the cron now reads two new tables (`post_event_hours`, `post_count_events`); wrong order = errors every minute.
- Card like/comment counts can now lag up to ~60s on a genuinely viral post; the person who acted always sees the exact number. Deliberate trade.
- Not Bagel still has no dev database branch, so its tests weren't run — it shipped on typecheck + query-plan proof only.
