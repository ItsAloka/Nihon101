## What we did
- **Fixed a HIGH bug — 2FA bypass:** the OTP `pending` ticket (signed with the same JWT secret, `purpose:'otp'`) was accepted as a Bearer access token, because `verifyAccess` (lib/tokens.ts) never checked `purpose`. Now it throws on any token carrying a `purpose` claim → 401. Added a regression test to `test/otp.test.ts`. Tests now 28/28 (was 27).
- **Added hourly auth-token prune:** new `db/queries/maintenance.ts` — `pruneDeadRefreshTokens` (revoked or expired) + `pruneExpiredAuthArtifacts` (used/expired password_resets, email_verifications, login_otps, and expired trusted_devices). Wired into the existing top-of-hour cron in `index.ts` alongside the notif/signal/stale-report prunes. NO migration.

## Important notes & decisions
- `refreshTokens.revokedAt` here is a nullable timestamp (dead = `revokedAt IS NOT NULL OR expired`), not a boolean — the prune accounts for that.
- Nihon101 vs Not Bagel are ~90% the same engine (identical rate-limiter, CSP, DB pooling, xss sanitizer, CI). These two were the only security/scale gaps where Not Bagel was ahead; now closed.
- Both Docker Postgres bind :5432 → run one at a time. Verified this session by stopping `not-bagel-pg`, `docker compose up -d` here, migrate, test green, then restored not-bagel-pg.
