## Important notes & decisions
- **RULE still holds:** the prototype IS the design — only swap data. New search dropdown was an owner-requested behavior, styled in the prototype's own `p.*` tokens.
- **The `is:global` gotcha:** Astro scopes `<style>` to a component; a shared layout's CSS won't reach slotted/child markup unless the style block is `is:global`. This bit us once (explore rendered unstyled).
- **Windows curl mangles kanji** to `??` before sending — always %-encode JA when testing search (saved as a memory).
- **Known non-bugs (logged as future work):** JA *body-only* substring search needs a JA analyzer (pgroonga/pg_bigm); the tag-filter `EXISTS` is a seq-scan (fine per "build first, optimize later"); `?page=99` shows an empty grid.
